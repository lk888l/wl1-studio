# Windows 应用内液态玻璃

Windows 的 WebView2 / Chromium 使用应用界面作为玻璃背景，窗口保持不透明，不读取桌面或其他窗口。其他平台保留原有界面材质。本次没有新增前端依赖，也没有修改 Rust 渲染、设备通信或窗口权限。

## 使用与覆盖范围

在产品首页打开「个性设置 → 液态玻璃」，选择「柔和 / 平衡 / 通透」，下方材质预览会即时更新，偏好继续使用现有本机存储。首页顶部栏、各工作台的导航侧栏和顶部栏、固件确认弹窗、电子琴连接弹窗、通知与电脑监控浮层已接入。

扩展覆盖范围包括：

| 区域 | 主要玻璃组件 |
|---|---|
| 产品首页与个性设置 | 六个产品入口、身份与主题设置、工作台偏好、设置保存状态 |
| WL1 | 连接栏、总览主卡片、图表与机器人预览、机身与 PID 参数组、实时控制、标定向导、运动学面板、诊断侧栏、固件操作面板 |
| GameBox | 连接栏、设备预览、状态与按键面板、游戏图鉴和存储 / 协议说明 |
| NFC | 连接栏、读取与卡片摘要、密钥补全、比对导入与摘要面板 |
| StickS3 | 连接栏、Wi-Fi / BLE 配置面板、记忆管理、网络探针查找与结果 |
| 桌宠与电脑监控 | 连接栏、像素编辑与动画预览、互动与操作说明、监控设置和资源 / 传输信息 |
| 电子琴 | 概览、曲谱工具栏与编辑器、虚拟琴键、按键映射、曲库摘要、演示烧录设置 |

内容面板采用较柔和的材质，保持参数、文字和图表清晰。密集数据行、终端、十六进制内容、设备屏幕内部、告警和危险操作按钮维持原有表现。已接入的玻璃组件之间避免再次嵌套液态滤镜。

玻璃组合了圆角边缘折射、轻微 RGB 色散、背景柔化、边缘高光与跟随指针的光照。中间区域保持平坦，前景文本、表单和按钮不经过滤镜。弹窗提高了底色浓度以保证文字可读。

## 实现

- `src/lib/liquid-glass.ts`：纯几何计算及三档参数。圆角矩形的有符号距离场与法线生成 R/G 位移图，使用 CSS 像素计算曲面，降采样后仍保持正确比例。每张图不超过 1024 像素边长和 262144 像素总量。
- `src/components/LiquidGlass.tsx`：共享平台与辅助功能检测、原生标签和 ref 转发、可视范围检测、ResizeObserver、SVG 背景滤镜及资源清理。位移图只在尺寸或曲面参数变化时生成；背景由浏览器实时合成，不截屏、不复制 DOM、不持续运行绘制循环。PNG 解码完成后才替换材质，并忽略过期结果，快速缩放回到缓存尺寸时也会撤销中途的解码结果。
- `src/components/LiquidGlass.css`：透光底色、光照、阴影及滚动层级。弹窗外部遮罩不再模糊背景，避免父级 backdrop root 隔断弹窗对界面的采样。

为新的上层组件接入时，保留原标签语义、属性和布局：

```tsx
import { LiquidGlass } from "./components/LiquidGlass";

<LiquidGlass as="header" className="topbar glass-panel">
  {/* 内容保持清晰，不应用普通 CSS filter。 */}
</LiquidGlass>
```

`App` 中的 `LiquidGlassProvider` 共享玻璃强度与减少动态设置。`LiquidGlass` 支持 `div`、`header`、`aside`、`section`、`dialog` 的原生属性与对应 ref。只有显式接入的上层组件启用折射，避免为所有数据卡片和嵌套容器创建 GPU 滤镜。

内容容器可使用 `variant="panel"`，并支持 `article`、`form`、`button` 标签及其原生属性。该材质缩窄折射边缘、降低位移强度，使用一次位移处理，保留静态高光；导航、弹窗与浮层默认使用 `surface`，保留 RGB 色散与指针光照。三档全局强度对两种材质均生效。

IntersectionObserver 在视口周围 160px 内预先准备材质；更远的组件卸载 SVG 滤镜、暂停尺寸监听与指针更新，并沿用兼容底色。回到可视范围后复用已经解码的位移图，尺寸改变时才重建，避免长列表持续占用合成资源。

现有 `img-src data:` 可加载内存生成的 PNG，内联 SVG 定义无需外部请求，不需要放宽 CSP。非 Windows Chromium 或材质生成失败时保留原有样式；系统减少透明度或强制颜色模式使用不透明材质。用户或系统减少动态效果时停止指针光照更新。

## 验证

运行 `npm run check:frontend`。`src/lib/liquid-glass.test.ts` 验证圆角双轴法线、镜像对称、中心无折射、边缘连续变化、尺寸比例、内存上限、无效输入及平台判定。

浏览器检查可直接使用 `npm run dev`，无需连接硬件：

1. 在 Windows Edge / Chrome 打开首页，滚动产品卡片，观察顶部栏后方的实时色彩和折射；进入各产品后检查导航和返回按钮。
2. 在个性设置切换三档材质，缩放窗口，检查材质尺寸、文字可读性和横向溢出。
3. 在预览上移动指针，再启用「减少动态效果」，确认光照回到静态；系统减少动态效果应具有相同行为。
4. 检查固件原生 dialog 与电子琴连接弹窗的打开、关闭、重新打开及背景层级；原生 dialog 保留 Escape 关闭行为。不要为检查效果执行烧录、擦除或真实连接。
5. 检查系统减少透明度、强制颜色模式及恢复后的材质切换；Linux、macOS 和非 Chromium 浏览器应保留兼容外观。
6. 滚动产品入口和长页面，确认远处面板暂停滤镜、进入视口后恢复；连续缩放、隐藏再显示面板时，材质尺寸应与组件尺寸一致。

本次自动浏览器验证使用 Windows Edge 与 Chrome，包括实际折射与同等模糊的像素差异、1440/1280/820/390px 布局、原生 dialog 的 ref 与 Escape、三档设置、动态效果开关、系统辅助功能模拟，以及生产资源在 Tauri CSP 下的加载。其他平台的回退通过 user agent 模拟检查，尚未在其原生 WebView 中执行。
