# SmartKnob 智能力反馈旋钮接入

产品库中的 **智能旋钮** 工作台对应 ESP32-S3 / DRV8316CT / MT6701 / 22008（7 极对）电机，支持原四种模式、可分别调参的参考预设与无摩擦保持。上位机只负责配置与监测，ESP32 独立完成触觉、电流闭环和保护。浏览器仅提供界面预览，真实 USB 调参需要 Tauri 桌面应用。

## 固件与协议基线

当前对齐 **`dma-v23-live-tuning` / `20k65_sampling`**（20 kHz PWM、5 kHz 电流控制）。`reference_config_version:2` 表示物理单位和独立点击开关，完整参数表位于 `config.reference_modes`。新版取消额外 0.45 A 手感上限，使用运行电流上限和原有保护。仍兼容 v21 参数版本 1、v20 固定预设和历史 15 kHz 构建；按设备能力字段选择界面，不通过版本名称猜测功能。

v22 使用与原档位相同的弹力/阻尼计算，每个模式拥有自己的参数。`strength` 范围 0–1000 A/rad，`damping` 范围 0–0.5 A·s/rad；`endstop` 为 0–20 A/rad，新增 `endstop_damping` 为 0–0.5 A·s/rad。输出倍率默认 1，仍只属于当前模式。点击默认关闭，勾选“启用切档点击”后可设置幅值；关闭会保留幅值，磁吸模式仅进入指定档位时点击。v23 通过 `live_haptics_config:true` 开放运行中参考参数更新；v21/v22 仍要求停机。日常更新写 RAM，明确保存才写 `reference_v2`，重启为停机。

升级时固件迁移旧参数：未修改的 v1 预设采用新默认，自定义条目保留几何并换算原有倍率；点击幅值保留但默认关闭。原电气配置和校准保持。旧 v1 设备仍显示原始增益与 0.45 A 约束，不伪装成 v2。下方运行模式表继续适用，旧 v21 参数表属于兼容契约。

`control_nominal_hz`、`encoder_nominal_hz` 和 `pwm_actual_hz` 接受有限正小数，保留设备原始精度；旧 `pwm_hz` 及载波分频仍按正整数校验。旧解析器把标称频率强制当成整数的问题已保留修复。

历史 15 kHz 构建的诊断显示 `pwm_actual_hz` 推导的 **15003.75 Hz** 载波；控制标称频率 **3750.94 Hz**、编码器标称频率 **2500.63 Hz**，分别附带 **每 4 / 6 个 PWM 周期**的更新关系。`control_hz` 仍单独标注为实测控制频率。其他固件缺少新字段时继续使用 `pwm_hz`，不推测分频。两相电流采样间隔使用设备实际上报值。

SmartKnob 工作台显示设备只读的自动电压能力，由有效的 PWM 上下界计算。当前参考模式构建为 **65%（相对 Vbus / √3）**，12 V 时约 4.503 V；历史 15 kHz 构建为 78.36%，12 V 时约 5.429 V。能力随实测母线变化；它不是实测绕组端电压，也不表示静止时强制满输出。完整线性 SVPWM 旧配置的 100% 范围仍可正常读取。

v8 起配置不再包含 `voltage_limit`，`voltage_limit_automatic:true` 标识自动最大值。解析器接受零最小软件脉宽，核对实际母线与可用/有效上限的关系；母线无效时允许能力正确归零并显示停机状态，而不会因合法的零值断开连接。参数应用、模式切换和预设应用都经同一配置序列化入口，新固件请求不会夹带旧电压字段。

旧 v4–v7 设备仍可读取，原电压限制只读展示；修改其他参数时保留设备已生效的旧限压，应用不提供该值的调整入口。是否自动最大化由经过校验的能力字段判断，不靠固件名称猜测。名义母线配置不覆盖实时测量，也不会决定 v8 的运行电压能力。

`timing_skips`、`sampling_recoveries`、`pwm_deferred`、`pwm_peak_duty` 和 `pwm_full_duty_cycles` 显示在诊断区。偶发无效窗口代表跳过更新；持续反馈不足时固件保持驱动使能、短暂使用零矢量恢复，界面不会将这些计数当作锁存故障。真实故障仍按设备的 `state` / `fault` 显示。

## 连接、在线调参与一键启动

1. 单个 ESP32 原生 USB 候选会自动选中；多个候选时选择串口。点击“一键连接并启动”后才连接并启动；也可选择“仅连接”，只读取设备真实状态、参数和校准。已在运行的设备直接接入，离线预览和旧会话草稿不会回放。
2. 已有有效校准时，启动复用校准并完成设备必需的电流零点采样。缺少校准时自动校准，电流为 `min(0.16, current_limit)` A、最大值为 `min(0.25, current_limit)` A，不自动提高运行上限；本次成功后在 idle 状态保存当前配置与校准一次，等待采样恢复，再启用。校准失败或保存失败不会继续启用。
3. 选择模式立即下发；数字输入按 Enter 或失焦后生效，连续步进调节采用 150 ms 防抖。开关、预设和恢复默认直接应用。设备响应期间仍可编辑，旧响应不会覆盖新输入。状态分别显示正在输入、等待下发、设备已生效或应用失败。
4. 输入不完整或参数组合非法时保留本地输入，设备保持最后有效配置。切换模式先提交有效的旧模式修改；无效输入保留到返回该模式处理，不阻止选择其他模式。每帧最多一个参考条目，公共配置基于最新回报，原浮点精度和未知扩展保留。发现外部配置冲突后暂停自动写入，使用“还原设备参数”重新同步。
5. 模式 0–3、参考模式 4–15 和无摩擦模式 16 的手感参数与运行电流上限可在线更新。参考参数要求明确的 `live_haptics_config:true`；缺字段的旧设备仍需停机应用参考条目，模式选择沿用其已有能力。母线、采样增益、Kp/Ki 使用独立电气草稿和“应用电气设置”，停机时才允许应用，不会夹带进手感请求。
6. 普通力度、阻尼调节保留中心，修改非当前模式不重置当前手感。同模式改档距或边界保留逻辑档位、就近限制到新范围，并以当前角度重建中心。初始逻辑档位仅在进入模式或显式归零时使用。配置改变当前手感时固件执行 20 ms 过渡，保留电流环、过流累计及高速保护；未修改的无摩擦参数不发送，实际调节也保留保持状态。
7. 日常实时修改只写 RAM；停机后“保存到设备 NVS”会先提交有效手感输入，再保存配置和校准，未处理的电气输入会阻止保存。只有一键启动确实完成了新的校准时才自动保存。重新上电仍为停机。
8. 启动可随时点击“停止力反馈”取消后续流程并停机。校准等待上限 130 秒，采样就绪和使能等待各 5 秒；失败、拒绝或超时不自动重发写入、不自动清除故障。断开、返回产品库和退出取消未执行步骤并释放会话；无租约固件保持当前运行状态，通信失败只表示状态未知。

只读默认值查询沿用 `status` 的 `reference_defaults:true`；普通实时请求沿用 `configure`。新增能力为可选布尔字段，协议仍为 v1，参考参数仍为版本 2。底层 Rust 串口会话保留请求 ID、会话令牌、长度限制和超时后不重发的规则。上位机不计算力矩。

## 默认值与能力边界

### 参考模式与无摩擦

当前固件的 17 个模式如下。界面模式名称取设备返回值；表内编号只说明当前固件约定，不作为判断其他固件能力的依据。

| 模式编号 | 含义 |
| --- | --- |
| 0–3 | 原自由旋转、虚拟档位、有限行程、弹簧回中 |
| 4 | Custom，默认为零力矩，可按参考参数自定义 |
| 5–7 | 无界平滑、有界 0–10、多圈平滑 0–72 |
| 8–9 | 强档位开关、回中 |
| 10–11 | 精细平滑、精细点击档位 |
| 12–13 | 粗调强档位、粗调弱档位 |
| 14–15 | 磁性档位、带档位回中 |
| 16 | 无摩擦保持 |

旧档距、强度、端点、阻尼和切档点只作用于模式 0–3。v21 为模式 4–15 各自保留独立的参考参数；切换模式使用该模式最后应用的参数，不覆盖其他模式，也不把参考参数转换成旧模式字段。名称对应原始预设模板，调参后的实际手感以当前参数为准。GUI 不复制触觉算法。运行电流上限作用于所有模式，v21 参考预设另有 0.45 A 上限；v22 以运行电流上限约束输出，倍率不会绕过保护。

正常 `status` 的 `config.reference_modes` 包含键 `"4"` 到 `"15"` 共 12 个完整对象。`configure` 中该对象是按模式合并的补丁：省略整个对象或某个模式会保留其现有值；提供模式条目时必须包含该条目的全部字段。上位机保留未编辑字段的原始浮点精度及未知扩展，仅发送发生变化的模式。TypeScript 和 Rust 将请求正文限制为 **1900 个 UTF-8 字节**，为固件 2047 字节输入帧内新增请求 ID 留出空间。

| v21 兼容参数字段（v22 差异见上方） | 含义与范围 |
| --- | --- |
| `bounded` | 是否启用行程边界；布尔值 |
| `position` | 启动、切换及归零后的初始逻辑档位，整数 ±10000 |
| `min_position` / `max_position` | 行程端点，整数 ±10000；有界时起点 ≤ 初始档位 ≤ 终点；无界时不使用端点顺序 |
| `width` | 档距，协议为 rad，界面为 1–180° |
| `strength` | 档位增益 0–100，与输出倍率相乘 |
| `damping` | 速度阻尼增益 0–5，与输出倍率相乘 |
| `endstop` | 端点增益 0–20；实际端点斜率为 `endstop × 4 × scale` |
| `snap` / `bias` | 切换点 0.5–2、中心偏置 0–1.5，且 `bias ≤ snap − 0.05` |
| `scale` | 输出倍率 0–1，缩放档位、阻尼与端点增益 |
| `friction` / `click` | 摩擦补偿与点击脉冲，分别为 0–0.45 A，不再乘输出倍率 |
| `magnetic_positions` | 最多 8 个不重复整数档位，有界时须位于行程内；仅模式 14 可非空，其他模式为 `[]` |

界面按模式和参数版本展示适用项。v21 的模式 14 没有档位点击，v22 可以选择进入磁吸档位时点击。v21 的 strength 是倍率前原始增益；v22 与原 0–3 同为 A/rad，默认倍率 1 时可直接比较。

“恢复当前模式默认参数”发送只读 `status` 请求并附带 `reference_defaults:true`；固件返回的 `reference_defaults` 是完整默认参数表，操作仅替换当前模式的本地草稿，不改变设备 RAM、当前模式或使能状态。之后仍需停机并明确应用。普通轮询不附带默认表。

显式保存将参考参数表写入独立、版本化并校验 CRC 的 NVS 记录：v21 使用 `reference_v1`，v22 使用 `reference_v2`。旧 `settings_v1` 电气配置、校准及 `frictionless_v1` 布局保持兼容；首次升级没有参考记录时使用默认预设，坏记录也只回退参考参数，不使原校准失效。上电仍停机，不依赖上位机恢复参数或持续刷新力矩。

模式 16 使用独立的 `config.frictionless` 对象。发送时保留五个完整字段以及设备返回的扩展字段，省略整个对象的旧客户端仍兼容；保存时由固件写入独立 `frictionless_v1` NVS 记录。

| 字段 | 单位 | 范围 |
| --- | --- | --- |
| `friction` | A | 0–0.8 |
| `viscous` | A/(rad/s) | 0–0.02 |
| `scale` | 无量纲 | 0–10 |
| `hold_kp` | A/(rad/s) | 0–1 |
| `hold_ki` | A/rad | 0–5 |

顶层 `frictionless` 遥测给出静止、诊断观察、保持、让步、起拨获取阶段，以及参考速度（rad/s）、修正和平均前馈（A）。无摩擦模式静止时持续零 Iq 闭环，`quiet_output=false` 本身不是异常；`scale=0` 可作零 Iq 对照，点击脉冲在此模式中无作用。

此次上位机接入不改变固件既有实机范围：约 ±10 rad/s 的 10 秒保持已通过此前验证，约 ±5 rad/s 的低速保持仍可能停止。显示“保持”仅表示固件状态，不能视为所有速度范围的机械验收。

### 原模式配置

以下为离线草稿及显示能力；已有设备参数始终以连接读回为准，不会自动应用离线默认值。

| 项目 | 默认值 | 上位机边界或含义 |
| --- | --- | --- |
| 模式 | 虚拟档位，mode=1 | 按设备能力；当前 0–16，旧版缺省 0–3 |
| 档距 width | 10° | 界面使用度，协议使用 rad；1°–180° |
| 强度 strength | 20 | 按 `strength_max`，主机最多允许 1000；v6/v7 为中心死区外的弹力斜率 A/rad |
| 端点强度 endstop | 8 | 0–20；当前配套设备保存为 20 |
| 阻尼 damping | 0.003 A·s/rad | 0–0.5 |
| 逻辑切档点 snap | 0.55 档距 | 0.5–1 |
| 行程 | 0–11 | 有序整数，范围 −10000–10000 |
| 运行电流 current_limit | 0.8 A | 最小 0.02 A；按 `current_limit_max`，主机最多允许 4.5 A |
| 电压能力 | 自动最大值（只读） | v8 完整 SVPWM 为有效母线 / √3；旧固件只读保留其已设限压 |
| 电流 PI | Kp=0.4、Ki=200 | Kp 0–20，Ki 0–1000 |
| 母线 bus_voltage | 11.62 V | 离线草稿默认值；4.5–30 V，实时采样固件中是名义配置，与实测母线分别显示 |
| 感测增益 sense_gain | 0.15 V/A | 仅支持 0.15 / 0.3 / 0.6 / 1.2，须对应硬件 GAIN |

`current_limit_max` 缺失时使用 **0.8 A**；`strength_max` 缺失时使用 **10**。旧固件报告 `strength_max:100` 时仍限制为 **100**；v7 报告 **1000** 时才放开至 **1000**。收到超过本应用支持范围的能力值时，仍受主机 **4.5 A / 1000** 上限约束。调高上限不会自动改写板上运行值或提高电流。

v6/v7 的 `detent_profile:"smart_knob"` 使用同一挡位中心完成迟滞换挡和弹力计算。死区为 `dead_zone = min(width × 0.2, π/180)`，静态切换前的目标电流幅值上界为 `min(current_limit, strength × max(width × snap − dead_zone, 0))`。例如 10°、snap=0.55、strength=10 时约为 0.785 A；动态目标另含速度阻尼，并经过速度包络、实测限流及电压能力限制。将 strength 从 100 提高到 1000 会使死区外的弹力斜率更陡、较小偏移就到达当前限流值，不能使 0.8 A 的运行限流变成 8 A。

旧 `detent_profile:"localized_barrier"` 使用 `min(current_limit, strength × width / 2)`，10°、strength=10 且未受更低 current_limit 截断时约为 0.873 A。两种公式均是算法目标，不是已经达到的实测电流或持续运行额定值；页面须按设备报告的曲线类型解释，不将旧公式用于 v6/v7。

v8 默认使用完整 SVPWM 电压圆，不再为公共低侧采样窗口设置固定占空比上限；窗口不足由固件反馈恢复处理。历史版本默认 4%–40% 占空比、11.62 V 母线时约为 **2.415 V**；历史 20k70 候选报告 0%–70% 调制跨度、19.4 V 名义母线时约为 **7.8404 V**。这是调制能力，并不表示当前输出了该电压或已经达到额定电流。电流仍取决于绕组、反电动势和电压余量。电流遥测按感测增益换算为相电流或 d/q 轴电流，电源输入电流不能直接替代这些值。

启用 GPIO11 母线采样时，顶层 `bus_voltage` 是控制器使用的实测值，`config.bus_voltage` 是名义配置；上位机不会把轮询实测值写回配置。v8 的 `configured_max_voltage_limit` 仅是名义配置的参考能力；`max_voltage_limit`、`available_voltage_limit` 和 `effective_voltage_limit` 都是当前实测母线对应的自动能力。旧固件仍按其历史契约核对已设限压与实时能力中的较小值，且不开放限压编辑。供电下降只改变实时能力，不把已有合法配置误报为越界。界面显示采样有效性和来源；无效或过期时不把旧读数显示为当前有效实测。缺少母线采样字段的旧固件仍使用手动配置。

## 遥测与磁场解释

仪表使用设备已生效的 mode、width、angle 和 position；未应用草稿不会伪装成硬件状态。电流曲线只追加 `current_valid:true` 的样本，绘制实测 Iq 及 `target × calibration.direction` 的 q 轴目标。量程随电流配置与有效曲线数据调整，避免固定 ±1 A 截断新固件数据；该图是主机轮询快照，不是完整的电流环采样波形。

诊断使用 `encoder`、`encoder_interface`、`encoder_resolution_bits` 和 `encoder_dma` 标识传感器通路。默认 MT6701 为 14 位 SSI/SPI DMA，保留的 AS5600 后端为 12 位 I²C。两者的 `magnet` 字段解释不同：

| 编码器 | 原始状态 | 含义 |
| --- | --- | --- |
| MT6701 | Mg[1:0]=0 / 1 / 2 / 3 | 正常 / 过强 / 过弱 / 保留异常 |
| MT6701 | Mg bit 3 | 失去跟踪，不能作为有效角度 |
| MT6701 | Mg bit 2 | 按压检测；单独置位不等于磁场异常 |
| AS5600 | MD bit 5、ML bit 4、MH bit 3 | 磁铁检测 / 偏弱 / 偏强；不按 MT6701 位定义解释 |

MT6701 正常状态可以带按压位，因此不能仅按 `magnet === 0` 判断正常，也不能套用 AS5600 的 `0x20` 或 `0x10` 判断。CRC / 通信失败、数据过期或硬件初始化失败时显示磁场状态未知，避免把默认值或旧值显示为正常；有效磁场强弱和失去跟踪状态仍分别展示。旧 AS5600 的 `weak_magnet_allowed` 不适用于 MT6701。

`velocity` 为高速包络使用的平滑速度，`velocity_fast` 为快速阻尼/预测速度；`voltage_d`、`voltage_q` 可用于判断电压能力是否饱和。故障锁存电流 `fault_currents` 及对应限值与实时电流分开解释，停机后无效实时读数不替代故障现场。缺失的新诊断字段显示为未知或不展示，不用零值假装已测量。

## 限流、手感与停机

工作台展示设备报告的保护值，不能把 `current_limit` 当成所有停机阈值。v4 的规则如下：

| 层次 | v4 行为 |
| --- | --- |
| 目标限流 | 目标不超过 `±current_limit`；实测超限降额，并为 d 轴电流保留余量 |
| 普通过流 | 达到 `min(5, current_limit + max(0.15, current_limit × 0.25))` A 后，累计超限暴露 20 ms 停机 |
| 快速过流 | 达到 5 A，累计暴露 1 ms 停机 |
| 紧急过流 | 达到 6 A，当前有效采样立即停机 |
| 暴露恢复 | 低于阈值时以四分之一速度恢复，避免短暂回落反复清空证据 |

相关遥测为 `current_trip_limit`、`current_peak_trip`、`current_peak_trip_ms`、`current_absolute_trip`、`current_overload_trip_ms` 和 `current_trip_recovery_ratio`。旧固件的阈值可能不同，页面按实际值显示。`current_target_limit` 表示降额后可用的 q 轴幅度，`current_limited` 表示正在限流。

v4 的 `haptic_position_filter:false`、`detent_quiet_velocity:false` 和 `current_target_slew:false` 表示旧挡位位置平滑、两区间速度分支及额外目标上升斜坡已经删除。它们不表示停用 PI、速度估计或实测电流限幅。严格零力矩意图下的 `quiet_output` 仍可清 PI 并静音，任何非零请求恢复连续电流控制。

挡位同向助推在 0–10 rad/s 保持全量，在 10–25 rad/s 递减；共同高速包络在 25–40 rad/s 渐弱，40 rad/s 暂停。降到 5 rad/s 或以下保持 30 ms 后才恢复，完整恢复约需 500 ms。`haptic_scale`、`speed_limited` 和 `haptic_paused` 表示临时手感限制，不等同于故障或驱动失能。

`host_lease_ms:0` 表示无主机租约，明确使能后固件可独立运行。工作台断开、离开产品、转入后台或退出时只释放连接，不发送 `disable`。只有明确停止操作才停机；设备报告非零租约时，通信超时仍按其固件规则触发 `host_timeout`。状态未知时不显示已确认停机。USB 回复上限为 **32768 字节**，容纳完整校准、参考参数表和按需默认表；连接时保持 DTR/RTS 关闭以避免 USB 控制线复位。
