# PN532 NFC 软件交付说明

本次按用户最终要求仅完成软件交付，不执行手机写卡测试。源代码修改保留在项目工作区。

## 已完成的改进

- PN532 串口响应核对、认证失败后的重新选卡与认证恢复，以及取消、超时任务的串行互斥。
- MIFARE Classic 1K / 4K 双密钥读取、7 字节 UID 认证、可读 Key B 与隐藏密钥的正确区分。
- 写入前校验备份和访问位，逐块写入与回读，按真实密钥重建尾块，默认保护原卡及厂商块。
- 明确区分数据缺失、密钥缺失、写入失败、跳过块与验证失败，避免将部分复制显示为完整成功。
- JSON 备份保存、导入校验，以及手机空白门卡的 UID 和写入权限说明。
- 回读对比：独立快照待对比区、A / B 选择、两次读卡结果对比，以及 JSON 文件多选 / 粘贴导入。按地址比较 UID、数据与确认密钥，高亮差异和未知内容，支持扇区与区域筛选。
- NTAG213/215/216 容量识别、读取地址保持与用户页写入校验，保留 UID、锁定位、配置和密码页。

## 验证结果

- 2026-09-17：`npm run check:frontend` 和 `npm run check:rust` 通过：88 项前端测试（含 19 项回读对比测试）、98 项 Rust 测试，以及格式、静态检查和前端构建。
- 浏览器操作验证通过：两次模拟读卡、快照保留、相同 UID 对比、A / B 交换、记录移除、JSON 粘贴与多文件导入、无效文件整批拒绝、离线对比和窄窗口布局。此次验证未访问串口、未写卡。
- 4 项需要设备的测试默认忽略，普通自动测试不访问读卡器。
- 已完成 PN532 1.6 串口握手和手机空白门卡只读实测：64/64 块及 16 个扇区的 Key A / Key B 信息取得。
- `npm run tauri -- build --no-bundle` 成功，在 Ubuntu 24.04.5 LTS x86_64 上生成 release 程序。
- 未对实体卡或手机卡执行任何真实写入。写入流程由虚拟串口与模拟卡测试覆盖，真实写入及门禁可用性尚未验证。

## 运行

解压交付包后，进入解压目录运行：

```sh
./wl1-studio
```

程序使用系统 GTK3、WebKitGTK 4.1 等运行库。当前构建基线为 Ubuntu 24.04 x86_64，其他系统的运行条件见 [Linux 说明](linux.md)。

包内的文件可通过 `sha256sum --check SHA256SUMS` 核对。NFC 工作台的使用步骤和支持范围见 [PN532 使用说明](nfc-pn532.md)。
