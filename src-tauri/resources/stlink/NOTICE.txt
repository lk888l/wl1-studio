WL1 Studio embeds the archive only in Windows x64 builds. Installation is an
explicit user action requiring Windows UAC; PnPUtil installs only the original
stlink_dbg_winusb.inf. No installation runs at build, startup or app install.
VCP/bridge INFs and the archive's legacy setup executables are not executed.
Windows ARM64 driver installation is not provided by this package.

Linux builds embed a ST-Link-specific uaccess rule, installed only on explicit
request through system authorization (pkexec). Linux needs no bundled driver.
